# EvidenceGate OCR v0.3.0

This release turns the public prototype into a stranger-reproducible, cross-domain open-source package.

## Added

- a copyable five-minute quick start with a frozen passing candidate;
- Simplified Chinese documentation;
- contribution guidance, bug template, domain-example template and pull-request checklist;
- Windows and Ubuntu CI;
- a 12-case synthetic arts-event publication suite using the same gate engine;
- a first-independent-user pilot guide;
- Skill triggers for content-management and publication workflows.

## Frozen v0.3 routing evidence

- base contract cases: 13;
- document adversarial cases: 30, with 0/20 dangerous false accepts and 0/10 overblocks;
- arts-event cases: 12, with 0/10 dangerous false accepts and 0/2 overblocks;
- human-correction replays: 3;
- real Bailian development evidence remains the frozen five-image, three-round v0.2 suite.

## Boundary

The arts-event suite is synthetic. This release does not claim production OCR accuracy, editorial accuracy, SLA, ROI, automatic approval, publication permission or business-state write access. Independent-user evidence remains future work.
